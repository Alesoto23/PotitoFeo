2. Traducir el enunciado: ¿intersección, unión, complemento o condicional?

La clave es leer la palabra que une los eventos. Primero define cada evento como un vector lógico (TRUE/FALSE) y luego combínalos.

Si el enunciado dice…Es…NotaciónEn R
"A y B", "A pero B", "A y además B", "ambos", "a la vez", "que cumpla A y que cumpla B"IntersecciónA ∩ Bmean(A & B, na.rm = TRUE)

"A dado que B", "si se sabe que B", "entre los que cumplen B", "de los que B", "sabiendo que", "condicional"CondicionalP(A | B)mean(A[B], na.rm = TRUE)
⚠ La trampa de la barra vertical "|"
En el enunciado (matemática), P(A | B) se lee "A dado que B" → es CONDICIONAL.
En R, A | B significa "A o B" → es UNIÓN.
Por eso nunca copies P(A | B) como mean(A | B). La condicional se escribe mean(A[B], na.rm = TRUE) (los corchetes = "solo entre los que cumplen B").
DiceSignificaR correctoR incorrecto
P(X | Y)X dado Ymean(X[Y], na.rm=TRUE)mean(X | Y)
P(X ∪ Y)X o Ymean(X | Y, na.rm=TRUE)mean(X[Y])
Truco: si ves "dado", "sabiendo", "entre los que" → corchetes [ ]. Si ves "o", "al menos uno" → |.

Cómo leer las barras (complementos) en una expresión

La barra niega todo lo que queda debajo de ella. Traduce de adentro hacia afuera y pon paréntesis donde termina la barra:

# P( barra(X ∩ Y)  ∩  barra(U ∪ O) )
mean(!(X & Y) & !(U | O), na.rm = TRUE)

# P( Ū ∩ Ȳ )   (barra solo sobre cada letra)
mean(!U & !Y, na.rm = TRUE)
Leyes de De Morgan (sirven para comprobar): !(A & B) = !A | !B y !(A | B) = !A & !B. Si al calcular ambas formas da el mismo número, lo hiciste bien.

3. Probabilidad empírica

Probabilidad empírica = proporción de filas que cumplen el evento. La media de un vector TRUE/FALSE es la proporción de TRUE.

X <- DF$Streamers > 10000
Y <- DF$PromCan < 200
round(mean(X, na.rm = TRUE), 2)          # P(X)
round(mean(X & Y, na.rm = TRUE), 2)      # P(X ∩ Y)
round(mean(X | Y, na.rm = TRUE), 2)      # P(X ∪ Y)
sum(X, na.rm = TRUE)                     # casos favorables (conteo)
NA: si una variable tiene datos faltantes, na.rm = TRUE ignora esas filas. Alternativa si el sistema marca error: filtrar antes DF <- DF %>% filter(!is.na(PromCan)).

4. Probabilidad condicional, independencia y disjuntos

round(mean(X[Y], na.rm = TRUE), 2)                          # P(X | Y)  forma corta
round(sum(X & Y, na.rm = TRUE) / sum(Y, na.rm = TRUE), 2)  # P(X | Y) = P(X ∩ Y) / P(Y)
round(mean(E[!M], na.rm = TRUE), 2)                         # P(E | no M)
OpciónCómo decidir (redondeando a 2 decimales)
IndependientesP(A | B) = P(A). Saber B no cambia la probabilidad de A. round(mean(A[B],na.rm=TRUE),2) == round(mean(A,na.rm=TRUE),2)
DependientesP(A | B) ≠ P(A).
Disjuntos (mutuamente excluyentes)No pueden ocurrir juntos: P(A ∩ B) = 0 → sum(A & B, na.rm = TRUE) == 0
NulosEl evento nunca ocurre: P(A) = 0.

5. Probabilidad total y Bayes (datos teóricos de un "experto")

Si A, B, C reparten todos los casos y te dan P(V|A), P(V|B), P(V|C), P(A), P(B), P(C):

PV  <- 0.90*0.025 + 0.30*0.475 + 0.05*0.500   # Probabilidad total: P(V) = Σ P(V|i)·P(i)
round(PV, 2)                                   # 0.19
round(0.90*0.025 / PV, 2)                      # Bayes: P(A|V) = P(V|A)·P(A) / P(V) = 0.12

# Comparar con lo EMPÍRICO
A <- DF$Pos <= 5;  V <- DF$Streamers >= 20000
round(mean(V, na.rm = TRUE), 2)                # 0.31
round(mean(A[V], na.rm = TRUE), 2)             # 0.21
Teórico menor que lo observado (de algo "bueno") → el experto es más pesimista. Teórico mayor → más optimista.

6. Variables continuas: función de densidad por partes

# 1) Definir la densidad por partes con ifelse (sin la k)
g <- function(x) ifelse(x > 0 & x <= 1, 4 - 3*(1 - x)^2,
                 ifelse(x > 1 & x <= 3, (x - 3)^2, 0))
# 2) k para que el área total sea 1
k <- 1 / integrate(g, 0, 3)$value;  f <- function(x) k * g(x)
round(k, 2)                                           # 0.18
# 3) Probabilidad = área bajo f
round(integrate(f, 1, 3)$value, 2)                    # P(X > 1) = 0.47
# 4) Valor esperado y desviación estándar
E  <- integrate(function(x) x   * f(x), 0, 3)$value
E2 <- integrate(function(x) x^2 * f(x), 0, 3)$value
S  <- sqrt(E2 - E^2)
round(E, 2); round(S, 2)                              # 1.01 y 0.56
# 5) Mediana teórica: F(m) = 0.5
round(uniroot(function(m) integrate(f, 0, m)$value - 0.5, c(0, 3))$root, 2)   # 0.96
# 6) Centralidad: CV = S/E*100 → si > 30% usar MEDIANA, si < 30% PROMEDIO
round(S / E * 100, 2)                                 # 55.52 → mediana

Validar un modelo (¿es bueno?)

m <- mean(DF$Streamers, na.rm = TRUE);  p <- 1/(m + 1)
round(sqrt((1 - p)/p^2), 2)                       # sd teórica   34055.08
round(sd(DF$Streamers, na.rm = TRUE), 2)          # sd empírica  61174.47
round(pgeom(m, p, lower.tail = FALSE), 2)         # P teórica(X > media) 0.37
round(mean(DF$Streamers > m, na.rm = TRUE), 2)    # P empírica           0.23
Si la sd y las probabilidades teóricas se parecen a las empíricas → el modelo es bueno. Si la sd teórica es mucho menor → no es bueno, "tiene una variabilidad mucho menor" (mucho mayor → "variabilidad mucho mayor").

PasoQué hacer

2Subraya la palabra que une: y → & · o → | · no / ni → ! · dado que → [ ].
3Si hay barras, pon paréntesis donde termina cada barra y antepón !.
4Calcula con round(mean(..., na.rm = TRUE), 2).
5Para comparar (independencia, modelo bueno, optimista/pesimista), compara los valores ya redondeados a 2 decimales.
